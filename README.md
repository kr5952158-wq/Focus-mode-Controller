# Focus Mode Chrome Extension

## 🚀 About
Focus Mode is a Chrome Extension built using JavaScript that blocks distracting websites and helps users stay productive.

When a blocked website is opened, a custom block page appears with options to:
- Allow temporary access (5 minutes)
- Go back to previous page

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Chrome Extension APIs

## ✨ Features
- Website blocking functionality
- Custom block page
- Popup interface
- Background script handling
- Timer-based temporary access

## 🔧 How to Install
1. Download the project
2. Open Chrome → Extensions
3. Enable Developer Mode
4. Click "Load Unpacked"
5. Select this project folder
